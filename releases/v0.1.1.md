# v0.1.1（2026-11-22）

> 终端接入进一步简化：一条 `ops-runner login` 完成注册；`doctor` 自动补齐依赖；
> 新增桌面 UI 与 `ops-runner upgrade` 的设计；发布产品 UI 设计稿与根路径官网方案。

## 亮点

- **登录即注册**：`ops-runner login` 打开浏览器登录平台，授权后自动获取设备 token 并注册；
  设备以 MAC 指纹（只存哈希）去重，同机重复登录复用原终端。
- **自动自举**：`ops-runner doctor` 按服务端清单安装 Node / Python 运行时与 sidecar 依赖，
  幂等、免 sudo、校验 sha256。
- **终端 UI 桌面化**：`ops-runner ui` 默认打开桌面应用（规划中，当前版本仍打开本地页面）。
- **`ops-runner upgrade`**：统一检测与升级 CLI 与终端 UI，支持 `--check` / `--channel` / 非交互。
- **注册 key / 配对码停用**：新设备统一走 `login`，历史记录只读可吊销。

## 变更

- 版本号统一为 `0.1.1`（runner / server / web）。
- 站点根路径改为项目介绍官网，运营后台统一 `/admin`。
- 产品 UI 设计稿：控制台、运营终端、智能助手、任务、社媒线索、Skill 市场、站点、Runner 注册、
  系统管理、登录与官网首页。

## 下载

| 文件 | 平台 | 校验 |
|---|---|---|
| `ops-runner-v0.1.1-darwin-arm64.tar.gz` | macOS Apple Silicon | 见 Release 附件中的 `.sha256` |
| `ops-runner-desktop` | 桌面应用 | 规划中，暂未发布 |

安装：

```bash
tar -xzf ops-runner-v0.1.1-darwin-arm64.tar.gz
sudo install -m 755 ops-runner /usr/local/bin/ops-runner
ops-runner doctor
```
