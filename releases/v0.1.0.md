# v0.1.0（2026-11-18）

首个可用版本：终端接入、任务闭环、真实浏览器 skill 与 Nairaland 发帖链路。

## 能力

- 终端接入：配对码 + 公司注册 key、心跳、在线状态、系统服务注册
- 任务闭环：建任务 → 长轮询投递 → 执行 → 回传；租约与跨公司隔离
- 真实浏览器 skill：`nairaland.board`、`vehicle.collect`（车辆素材 + 图片落盘）
- 发帖：`nairaland.post`（headed Chrome、dryRun、4 图附件、编辑已有帖）
- 发布幂等：同一 VIN 只能成功发一次；异常进人工复核
- 终端安装清单：运行时 / 工具 / skills 上报

## 已知限制

- 定时调度、pipeline 执行器、LLM 意图解析未实现
- Cloudflare 放行凭据会过期，需要人工在终端过一次验证
